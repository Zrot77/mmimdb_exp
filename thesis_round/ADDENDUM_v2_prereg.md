## 0. 공통 규칙

- 통계: 짝지은 차이 d_s(seed 또는 fold별) → mean, SE = sd(d, ddof=1)/√n, 95%CI = mean ± t·SE. n=3 → t=4.303(df=2), n=5 → t=2.776(df=4). 보고에 n·df 명시. std는 ddof=1.
- 처방 효과 판정 용어(모든 실험 공통): CI 하한 > 0 → **"개선"**, CI가 0 포함 → **"구분 불가"**, CI 상한 < 0 → **"악화"**.
- 붕괴 임계값(데이터셋의 기존 사전기준을 따름): macro-F1 데이터(MM-IMDb, PAD) **0.05** (B2 게이트 값), AUROC 데이터(ESBL) **0.03** (C4 H1 값).
- γ는 모든 데이터셋에서 **γ=8** 로 통일(각 데이터셋에서 이미 실행·선택된 값, 새 선택 없음). ModDrop p=0.3.
- 테스트셋으로 아무것도 선택하지 않는다. 필요한 per-seed 원자료가 없는 셀은 대체·추정하지 않고 제외하며 목록을 보고한다.
- 환자 데이터(ESBL)는 사용자 PC에서만 처리하고 집계 수치만 보고한다.

## E1. 부분 결손 평가 (일부 환자만 결손)

**문제의식:** 기존 평가는 test 전원에서 같은 그룹을 결손시켰다. 이 경우 가법 모형(XGBoost depth-1)에서는 모든 환자에 같은 상수가 더해져 AUROC가 구조적으로 변하지 않으며, MLP도 둔감할 수 있다. 실제 임상은 일부 환자만 결손이다.

**설계(ESBL):**
- 결손 비율 q ∈ {0.1, **0.3(주)**, 0.5}. 각 (seed s, 그룹 g, q)마다 test 환자 중 비율 q를 무작위 선택(난수 seed = 1000·s + 10·(그룹 순번) + round(10·q)). 같은 (s,g,q)에서는 모든 모델이 같은 환자 집합을 쓴다.
- 모델: C3·C5와 동일하게 재학습(seed 0~4). XGBoost: 17변수 모델, 결손대응 NaN판·0판, R_g(그룹 g 제외 재학습). MLP: zf, γ8, ModDrop, R_g(MLP).
- 단순 결손: 선택된 환자만 그룹 g 결손(XGBoost: NaN, G_rec·G_bed는 0도; MLP: 그 환자의 z_g=0).
- **상한(패턴 하위모델, oracle):** 선택된 환자는 R_g 모델의 예측, 나머지는 같은 계열 full 모델(XGBoost 17변수 / MLP zf)의 예측으로 계산한 AUROC.
- 부분결손 붕괴 폭 = oracle − 단순결손(zf 또는 17변수 모델).

**설계(PAD):** B3에 저장된 체크포인트(zf, γ8, ModDrop; seed 0, fold 0~4) 재사용. 케이스: image_missing(주, 메타만 남음)과 meta_missing. q·난수 규칙 동일(fold를 s 자리에). 결손 방식은 B3와 동일(image_missing: pi=0, meta_missing: 지시서 B0 정의 = 메타 입력 0). oracle: 선택 환자는 E2의 단일모달 모델(only_meta / only_image) 예측, 나머지는 zf full 예측. 지표 macro-F1(argmax).

**판정(주 q=0.3, 그룹·케이스별):**
- E1-H1: 부분결손 붕괴 폭(seed/fold 평균) ≥ 임계값 → "부분결손 붕괴 있음", 아니면 "없음".
- E1-T(처방 효과): XGBoost 결손대응(NaN판 vs 단순NaN, 0판 vs 단순0) / MLP·PAD의 γ8 − zf, ModDrop − zf → 공통 용어(개선/구분 불가/악화).
- E1-H2: 붕괴 있음일 때만 (처방 − 단순)/(oracle − 단순) ≥ 0.5 → "수렴".
- q=0.1, 0.5는 민감도로 보고(판정은 q=0.3만).

## E2. 붕괴 정의 통일

**문제의식:** 붕괴 정의가 MM-IMDb·PAD는 "선형 probe 천장 − 결손 성능", ESBL은 "그룹 제외 재학습 모델 − 결손 성능"으로 달라 데이터셋 간 비교가 불확실하다.

**두 정의를 모든 데이터셋에서 계산(전원결손 프로토콜):**
- 정의 R(재학습 천장): 남은 모달/그룹만으로 **같은 모델 계열**을 학습한 성능 − zf 결손 성능.
- 정의 L(선형 천장): 남은 모달/그룹 특징에 선형 분류기(다항/이진 로지스틱, C=1, max_iter 2000, 오버샘플링 없음)를 학습한 성능 − zf 결손 성능.
- ESBL: R은 C3(XGBoost)·C5(MLP) 방식 그대로, L은 남은 16~14개 변수(MinMax, train fit)에 로지스틱.
- PAD: L = 기존 suff(raw). R = 새 단일모달 모델 `only_meta`(분류기 입력 (0, pm), CE, 보조 head 없음), `only_image`((pi, 0)). 나머지 설정은 B3 zf와 동일. 5 fold, seed 0.
- MM-IMDb: L = 기존 suff(이미지 raw / 텍스트 raw). R = 새 단일모달 모델. `image_only`: 분류기 입력 (pi, 0), BCE만(텍스트를 보지 않으므로 InfoNCE·align 항 제외), 그 외 L0 설정·조기종료 동일. `text_only`: (0, pt), BCE만. 백본 CLIP·SigLIP so400m, seed 1·2·3.

**판정(셀별):** 두 정의의 "붕괴 있음/없음" 결론(임계값 기준)이 같으면 **"정의 간 일치"**, 다르면 **"불일치"**. 수치는 둘 다 보고.

## E3. PAD seed 확장

- 조건: zf, γ8, ModDrop(p=0.3) × seed {1, 2} × fold 0~4 (30 run). 설정은 B3와 동일(`--seed`만 변경), 체크포인트 저장.
- 분석 단위: fold별로 seed {0,1,2} 평균을 낸 값(n=5, df=4). γ는 B3에서 선택된 8로 고정(재선택 없음).
- 판정: B3의 P1(γ8−zf), P2, P3(γ8−ModDrop), P4 규칙을 그대로 적용. 기존 seed 0 판정과 나란히 보고.

## E4. 통합 분석 (붕괴 폭과 γ 이득의 대응)

- 셀(전원결손 프로토콜): MM-IMDb {CLIP, SigLIP} × {text_missing, image_missing}, PAD × {image_missing, meta_missing}, ESBL-MLP × {G_rec, G_bed, G_vit, G_lab}. (ESBL-XGBoost는 γ가 없어 제외.)
- 셀(부분결손 프로토콜, q=0.3): PAD × 2 케이스, ESBL-MLP × 4 그룹.
- 붕괴 폭: E2 정의 R(주). 정의 L로도 같은 판정을 반복해 보고.
- γ 이득: γ8 − zf (결손 케이스 지표, paired CI; MM-IMDb n=3, PAD n=5 fold, ESBL n=5 seed).
- **판정(프로토콜별):** 붕괴 있음(≥ 임계값) 셀은 모두 γ 이득 "개선"(CI 하한>0)이고, 붕괴 없음 셀은 모두 γ 이득이 "개선"이 아니면(CI 하한 ≤ 0) → **"지지"**. 하나라도 어긋나면 **"불지지"**(어긋난 셀 목록 보고).
- 기술(판정 없음): 셀 간 붕괴 폭과 γ 이득의 Spearman ρ(데이터셋 혼합, 지표 척도 상이하다는 점 명시).

## E5. 수치 감사 (판정 없음)

- A0 정본표의 not_found·미완 항목 출처 추적 또는 재계산, 논문 인용 수치의 출처 로그 경로 확정.
- 모든 보고 std를 ddof=1로 통일한 표 작성.
- E2·E4에 필요한 MM-IMDb per-seed 원자료(zf·γ8의 text_missing·image_missing·full) 확보 여부 확인.

## 알려진 한계 (사전 명시)

- seed·fold 기반 CI는 학습·마스킹 무작위성만 반영하고 test 표본 변동은 반영하지 않는다.
- ESBL oracle은 서로 다른 모델의 확률을 섞으므로 두 모델의 보정(calibration) 차이가 AUROC에 영향을 줄 수 있다(두 모델 모두 같은 오버샘플링을 거침). PAD는 argmax 기반 macro-F1이라 해당 없음.
- MM-IMDb 부분결손 평가는 체크포인트 부재로 하지 않는다.
- 데이터셋 3개는 이미지 유무·모델 구조·규모·과제가 동시에 달라, E4가 "지지"여도 인과적 원인(무엇이 붕괴를 만드는가)은 분리되지 않는다.

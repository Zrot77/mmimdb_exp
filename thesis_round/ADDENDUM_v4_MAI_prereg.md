# 추가 실험 v4 — 제안 방법 MAI(결손 인지 추론) 사전 고정

- 작성: 2026-11-11, PAD 보조 분류기 출력을 한 번도 추출·열람하기 전
- 이 문서는 PAD 출력 추출(v2_pad_heads_dump.py) 실행 전에 커밋한다. 분석 스크립트는 이 파일의 md5를 출력에 남긴다

## 1. 배경
- E9-H(MM-IMDb)에서 γ가 학습한 남은 모달 보조 분류기는 천장 가까이 좋지만, 결손 입력을 받은 융합 분류기는 그 정보를 쓰지 못했음
- 이 진단에서 바로 나오는 처방: 결손이 생기면 융합 분류기 출력과 남은 모달 보조 분류기 출력을 섞고, 결손 조건별로 판단 기준을 다시 맞춤
- MM-IMDb에서는 보조 분류기 단독 사용(α=1) + 재보정의 결과를 이미 봤음(사후 관찰) → MM-IMDb는 개발용, PAD는 확인용

## 2. 방법 정의 (MAI)
- 학습: γ 학습 1회(γ=8, 기존과 같음). 추가 학습 없음
- 추론: 결손 조건 c는 테스트 때 알려져 있다고 가정(입력이 없는 모달은 보임)
  - full: z = 융합 분류기(full) — 기존 γ8과 같음
  - 모달 m 결손, 남은 모달 r: z_c(α) = α · head_r(p_r) + (1 − α) · cls(zero-fill)
- α 선택: 격자 {0.0, 0.1, …, 1.0}, 결손 조건마다 val의 순위 지표가 최대인 값, 동률이면 작은 α
  - MM-IMDb: val macro AUPRC(라벨 평균) / PAD: val macro one-vs-rest AUROC
- 판단 규칙
  - MM-IMDb: z_c(α)에 라벨별 기준값 재보정(정확 탐색, val) — v2 분석과 같은 함수
  - PAD: argmax(재보정 없음). 이유: PAD val 재보정은 신뢰할 수 없음이 이미 확인됨(pad_v2_recal_cause, 2026-11-08) — 이 결정은 보조 분류기 출력을 보기 전에 함
- 절제: α=0(= γ8 융합), α=1(보조 분류기만), MAI의 재보정 제거(MM-IMDb, F1@0.5)

## 3. 데이터 역할
- MM-IMDb(CLIP·SigLIP, seed 1~5, 저장된 로짓, n=5, t=2.776): 개발·기술 통계. 판정 없음
  - 개발 점검 규칙: 어떤 셀에서든 MAI − α=1 또는 MAI − α=0이 재보정 F1로 '악화'면 설계 결함으로 보고, PAD 추출 전에 이 문서를 개정(v4.1)하고 이유를 기록
- PAD(γ8 seed 0~2 × fold 5, 기존 체크포인트에서 보조 분류기 출력 추출): 확인. fold마다 seed 3개 평균 후 fold 짝지음(n=5, t=2.776, ddof=1)
- ESBL(선택): 붕괴가 없는 대조. 실행하면 별도 문서로 사전 고정

## 4. PAD 가설과 판정 (사전 고정)
- 셀: image 결손(메타가 남음, 주 판정 셀, 보조 = head_m) / meta 결손(이미지가 남음, 키 meta_missing_input0, 보조 = head_i)
- 지표: macro-F1(argmax, labels 0~5)과 macro OvR AUROC(softmax, test에 양성·음성이 모두 있는 클래스만)
- 비교
  - P1 MAI − γ8 융합 (주)
  - P2 MAI − ModDrop
  - P3 MAI − zf
  - P4 MAI − 천장 R(only_meta / only_image, seed 0)
  - P5 보조만(α=1) − γ8 융합 (E9-H의 PAD판, 설명 검정 보고)
- 주 판정(image 결손)
  - "확인": P1 macro-F1 개선 그리고 P2 macro-F1이 악화 아님
  - "부분 확인": 확인 조건은 아니지만 P1이 어느 셀·어느 지표에서든 개선
  - "불확인": 위 둘 다 아님
- full 조건에서 MAI는 정의상 γ8 융합과 같음(비용 0)
- 결과가 불확인이면 그대로 보고하고, 논문에서 MAI는 'MM-IMDb에서의 관찰'로만 씀

## 5. 점검
- K0: 새로 추출한 융합 로짓이 기존 V2/dump의 같은 체크포인트 로짓과 같아야 함(최대 |차| 출력, 1e-4 넘으면 경고)
- K3: 라벨 동일성(같은 fold의 모든 run)
- 추출 스크립트는 보조 분류기 성능을 출력하지 않음(K0와 개수만)
- 자체 시험: 가짜 로짓 양성 대조(보조가 좋을 때 α가 1 쪽, MAI > 융합, PAD 판정 "확인")와 음성 대조(보조가 정보 없는 잡음일 때 α가 0 쪽, MAI ≈ 융합, PAD 판정 "불확인")
  - 참고: 약하지만 정보가 있는 보조 분류기는 섞으면 실제로 도움이 될 수 있음(독립 잡음 평균 효과) → 이것은 결함이 아니라 방법의 의도된 동작

## 6. 한계 (미리 적음)
- α 선택과 재보정에 같은 val을 씀
- PAD val은 fold당 약 15%로 작음, 클래스 MEL이 작음
- MM-IMDb는 개발에 쓴 데이터라 확인 근거가 아님
- 테스트 때 결손 조건을 안다고 가정함(부분 결손·노이즈 결손은 다루지 않음)
